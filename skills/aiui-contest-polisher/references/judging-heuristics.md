# AIUI Contest Judging Heuristics

## Strong AI Glasses Signals

- Starts from what the user is looking at, not from a text prompt.
- Uses short visual states that are readable at a glance.
- Converts recognition into interpretation, memory, action, or challenge.
- Has a memorable ending instead of an endless assistant loop.

## Winning Demo Pattern

```text
see object -> lock target -> reveal why it matters -> interact -> reward
```

## Red Flags

- Looks like a phone app squeezed into glasses.
- Requires unreliable network or live recognition for the first demo.
- Has no fallback if preview taps or device setup fail.
- Says "published" without upload and launch evidence.

## Submission Copy Formula

```text
Most demos stop at naming the object.
This app asks what the user should notice and why it matters.
On glasses, that is the difference between recognition and discovery.
```
