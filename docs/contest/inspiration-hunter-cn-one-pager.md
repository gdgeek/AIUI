# 灵感猎手中文评委一页纸

日期：2026-06-04

## 项目一句话

`灵感猎手 Inspiration Hunter` 是一个面向 Rokid AIUI / Craft 的 AI 眼镜应用：用户看向一个真实物体，眼镜不只是说出“这是什么”，而是把它变成一次可交互的发现、故事和线索挑战。

## 核心亮点

- `眼镜原生体验`：入口不是聊天框，而是用户眼前正在看的真实对象。
- `可稳定演示`：比赛版本使用确定性的精选场景，避免现场识别链路不稳定影响路演。
- `有记忆点`：从扫描、锁定、揭示到挑战答案，60 秒内形成完整故事弧。
- `可扩展`：后续可以接入实时视觉识别，扩展到博物馆导览、城市探索、零售学习和研学场景。
- `可发布`：已准备 GitHub 源码、Craft 导入路径、本地 AIX 包、图标、发布清单和 Lingzhu 上传材料。

## 为什么适合 AI 眼镜

很多识别 Demo 停在“命名物体”。但 AI 眼镜的优势不是把手机聊天窗口搬到眼前，而是在用户注意力已经落在某个物体上时，立刻给出下一步：我应该注意什么？它为什么重要？我能不能马上参与一下？

`灵感猎手` 的产品判断是：眼镜上的 AI 应该从“看见”开始，而不是从“输入问题”开始。

## 60 秒 Demo 节奏

1. `0-10 秒`：打开灵感猎手，展示扫描界面和目标锁定。
2. `10-25 秒`：点击开始解析，展示物体身份、洞察、故事和意义。
3. `25-40 秒`：点击深挖和收藏，展示不是聊天流，而是眼镜上的即时反馈。
4. `40-60 秒`：进入挑战模式，揭晓答案，用一个奖励状态结束演示。

## 90 秒路演话术

大家好，这是 `灵感猎手`，一个为 Rokid AI 眼镜设计的发现型应用。

我们看到很多视觉识别 Demo 都停在一个很浅的问题：这是什么？但在眼镜上，真正有价值的问题其实是：我正在看的东西有什么值得注意？为什么它重要？我下一步可以做什么？

所以灵感猎手不是把聊天机器人搬到眼镜上，而是把用户眼前的真实物体变成一个短的发现循环：先扫描和锁定目标，再揭示它的身份、背景和故事，然后给出一个小挑战，让用户用线索完成一次互动。

当前比赛版本选择了一个可稳定演示的精选海报场景，保证现场 60 秒内能完整跑通扫描、解析、深挖、收藏和挑战答案。它的 UI 和交互是真实的，数据是确定性的，这样比赛演示不会被现场网络或识别链路拖垮。

同时，这个结构是可以扩展的。以后只要把确定性场景替换成实时视觉识别结果，同一套体验就可以进入博物馆、城市探索、零售学习和研学导览。

一句话总结：灵感猎手不是一个眼镜上的聊天框，它是从“你正在看什么”开始的 AI 发现循环。

## 评委可能会问

### 这是实时识别吗？

当前比赛版本是半真实 Demo：UI、交互、页面结构和发布包是真实的；识别目标使用确定性精选数据，目的是保证现场演示稳定。后续可以把场景选择接入实时相机识别。

### 技术完成度在哪里？

项目包含三个 AIUI 页面、页面 schema、图标资源、AIX 包、本地校验脚本、Pitch Deck、发布清单和 Lingzhu 上传交接文档。

### 最大的产品价值是什么？

它把 AI 眼镜的入口从“我问 AI”变成“AI 帮我理解眼前世界”，更贴近眼镜设备的天然交互优势。

## 结尾金句

`灵感猎手不是把聊天机器人搬到眼镜上；它让 AI 从用户正在看的真实世界开始工作。`
